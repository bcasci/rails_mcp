# Security Policy

`rails_mcp` exposes a hand-picked allow-list of Rails app actions to an AI client. A
vulnerability here can widen what an AI can reach, so please report issues privately.

## Supported versions

Security fixes are provided for the current `0.2.x` line.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a vulnerability

**Do not open a public issue for a vulnerability.** Public issues disclose the problem before
a fix is available.

Instead, email the maintainer privately at
[brandon.casci@gmail.com](mailto:brandon.casci@gmail.com) with:

- a description of the issue and its impact,
- the affected version(s), and
- steps to reproduce (a proof of concept if you have one).

## Response expectations

You can expect an initial acknowledgement within 7 days. We will keep you informed as we
investigate, agree on a fix and a coordinated disclosure timeline, and credit you in the
release notes unless you prefer to remain anonymous.
